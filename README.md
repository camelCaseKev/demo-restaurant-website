# demo-restaurant-website
A site for a fictitious restaurant, primarily created to practice creating and manipulating a relational database. This was my final project for a server-side development course at Lake Superior College. 

***Framework:*** Bootstrap  
***Languages:*** HTML/CSS, JavaScript, PHP, SQL  
***Database Client:*** phpMyAdmin  
***Database:*** MariaDB  

See website here: https://sickleswebdesign.webhostingforstudents.com/cis1610/final/home.html  
NOTE: Recipe manipulation is currently disabled
